## 📌 1. Project Overview & Problem Statement

Engineering students in India across all 4 academic years frequently ask:
- *"What should I learn in my current year?"*
- *"Which technical skills actually matter for my engineering branch?"*
- *"What real-world projects should I build instead of generic tutorial clones?"*
- *"When should I start preparing for internships and campus placements?"*

**SkillPath AI** is an intelligent, personalized career-planning platform built specifically to guide B.Tech students from their **First Year Foundation** through **Second Year Skill Development**, **Third Year Industry Preparation**, to **Fourth Year Placement & Career Execution**.

## 🌟 2. Key MVP Features

### 🎓 1. Academic Year Selection & Interactive Onboarding
- Guided 3-step onboarding wizard collecting:
  - Current Academic Year: **1st, 2nd, 3rd, or 4th Year**
  - Engineering Branch: **ECE, CSE, IT, EEE, Mechanical, Civil, or Other**
  - Primary Career Goal:
    - *Embedded Systems and IoT*
    - *VLSI and Semiconductor Design*
    - *Software Development*
    - *Artificial Intelligence and Machine Learning*
    - *Data Science*
    - *Core Engineering*
    - *Government Jobs & PSU (GATE)*
    - *Higher Studies & Research*
    - *Not Decided Yet*
  - Current Confidence Level: **Beginner, Intermediate, or Advanced**
  - Available weekly study hours target (5 to 40 hrs/week)
  - Dream target company (e.g. *Texas Instruments, Qualcomm, Microsoft, ISRO*)
- Generates a branch-specific personalized roadmap immediately upon completion.
- Allows students to edit degree details anytime from the top navigation bar or settings.

### 🗺️ 2. Personalized Year-Wise Roadmap
- Structured chronological engineering progression:
  - **1st Year (Foundation):** C/Python programming logic, engineering math, basic circuit labs, Git & GitHub, terminal workflows, and initial portfolio mini-projects.
  - **2nd Year (Skill Development):** Microcontrollers (UART/SPI/I2C), PCB design with KiCad, Verilog HDL / ModelSim simulation, Data Structures & Algorithms, Object-Oriented Design, and hackathon participation.
  - **3rd Year (Industry Preparation):** RTOS & ESP-IDF, FPGA Vivado synthesis, distributed system design, deep learning in PyTorch, ATS resume drafting, timed quantitative aptitude tests, and cold internship outreach.
  - **4th Year (Placement & Career Execution):** ATS Jake's resume formatting, technical whiteboard mock interviews, HR behavioral STAR method rehearsal, final-year IEEE capstone completion, campus drive tracking, and offer evaluation.
- Every task includes: unique ID, title, description, category, academic year, priority badge (High/Medium/Low), estimated study hours, prerequisites, documentation/course link, and status controls (**Not Started**, **In Progress**, **Completed**).
- Timeline milestone visualization and instant filters by Year, Category, Priority, and Status.
- Modal to add custom university course or project milestones.

### 📋 3. Interactive Skill Checklist (8 Essential Dimensions)
- Categorized across 8 standard engineering skill pillars:
  1. *Programming and technical fundamentals*
  2. *Branch-specific engineering skills* (Embedded C, Verilog, CMOS, Power Electronics, CAD)
  3. *Tools, platforms, and technologies* (Git, Docker, KiCad, Vivado, Linux Shell)
  4. *Practical laboratory skills* (Digital Oscilloscopes, Logic Analyzers, Breadboard soldering, Postman)
  5. *Projects and portfolio* (README documentation, personal site deployment)
  6. *Communication and aptitude* (Speed arithmetic, Group Discussion etiquette)
  7. *Resume and internships* (ATS format, LinkedIn networking)
  8. *Placement and interview preparation* (Core subjects revision, behavioral interview stories)
- Interactive checkboxes and status selectors updating metrics immediately.
- Category-wise completion percentages and overall verified count.
- **AI Skill Mentor:** Click *"Why it matters"* on any skill to receive instant contextual advice on how recruiters evaluate it in technical interviews.

### 🚀 4. Branch-Specific Project Discovery & Blueprint Engine
- Curated project library tailored by branch, academic year, and difficulty:
  - **ECE:** Smart LED Traffic Automation, Multi-Sensor Environmental Node, ESP32 MQTT Smart Home Gateway, Ultrasonic Distance OLED Meter, 32-Bit ALU in Verilog, FreeRTOS Industrial Wireless Node, 2-Layer Custom PCB in KiCad, 5-Stage Pipelined RISC-V RV32I Processor Core, Edge-AI TinyML Defect Camera, and OpenLane Sky130 ASIC GDSII Flow.
  - **CSE / IT:** Terminal Grade & CGPA Calculator, Full-Stack Event Registration Portal with QR Check-In, Automated Resume ATS Matcher, Distributed Raft Key-Value Store, Multimodal RAG Assistant with Citations, and Kafka E-Commerce Microservices.
  - **EEE:** Microcontroller Solar Power Meter & Battery Charger.
  - **Mechanical & Civil:** 3D-Printed Inverse Kinematics Robot Arm, Smart Campus GIS Stormwater Drainage in EPA-SWMM.
- Complete blueprints: Problem statement, components, step-by-step implementation, expected output, and testing suggestions.
- **"My Projects" Tracker:** Save projects to personal portfolio, manage status (**Planned**, **In Progress**, **Completed**), record start/completion dates, and track notes.
- **AI Project Ideator:** Generate custom project blueprints tailored to specific interests.

### 📊 5. Dynamic Progress Tracker & Dashboard

- Node.js (v18 or higher recommended; tested on Node.js v24)

### Steps to Run Locally

```bash
# 1. Clone or open the repository folder
cd "c:\Users\RAM CHARAN\OneDrive\Documents\ram"

# 2. Install dependencies
npm.cmd install

# 3. Start local development server
npm.cmd run dev
```

Visit the displayed local server URL (typically `http://localhost:5173`) in your web browser.

### Optional: Configure Gemini API Key

Create a `.env` file in the root directory:
```env
VITE_GEMINI_API_KEY=your_gemini_api_key_here
```
*(Or enter your key anytime in the **Settings** page within the app).*

## 🌐 6. Public Deployment Guide

The application is completely prepared for zero-cost deployment on **Vercel** or **Netlify**.

### Deploying to Netlify
1. Connect your GitHub repository to Netlify.
2. Build Settings:
   - **Build Command:** `npm run build`
   - **Publish Directory:** `dist`
3. Netlify automatically picks up `public/_redirects` for Single Page Application (SPA) routing.
4. (Optional) In *Site Settings > Environment Variables*, add `VITE_GEMINI_API_KEY`.

### Deploying to Vercel
1. Import your project repository into Vercel.
2. Framework Preset: **Vite**.
3. Build Settings:
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
4. The included `vercel.json` ensures all route requests rewrite cleanly to `/index.html`.
5. (Optional) In *Settings > Environment Variables*, add `VITE_GEMINI_API_KEY`.
